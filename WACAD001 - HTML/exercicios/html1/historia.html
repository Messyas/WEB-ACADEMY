História do HTML

Tim Berners-Lee (Físico britânico) criou o HTML original (e outros protocolos associados como o HTML), numa estação NeXTcube, usando o ambiente de desenvolvimento NeXTSTEP internet do CERN. A sua solução, combinada com a então emergente internet pública (que tornar-se-ia a Internet), ganhou a atenção mundial.

Bubble Sort

Exemplo de código Javascript:

        function bubbleSort(array) {
            for (let i = 0; i < array.length; i++) {
                for (let j = i + 1; j < array.length; j++) {
                    if (array[i] > array[j]) {
                        let aux = array[i];
                        array[i] = array[j];
                        array[j] = aux;
                    }
                }
            }
        }
        
        let numeros = [82, 76, 6, 52, 45, 38, 24, 14, 54, 85, 143, 98, 65, 512, 96, 12, 4, 79];
        bubbleSort(numeros);
        console.log(numeros);
        
        // posso reaproveitar a função para ordenar outro array
        let outroArray = [1, 5, 34, 2, 6, 7, 8, 12];
        bubbleSort(outroArray);
        console.log(outroArray);
